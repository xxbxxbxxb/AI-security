## 近 72 小时补读：事实、观点、创新与价值

### 1. 前沿训练环境：按“内层可能失守”设计外层隔离

- **事实/日期**：[OpenAI 官方披露](https://openai.com/index/securing-our-frontier-model-training-environment/)标注 **10/23**。其称前沿训练和多数评测使用离线网页内容环境，叠加沙箱、microVM、监测、网络及云侧边界；受控红队在专用副本中发现漏洞、配置问题与跨隔离通信途径。文中 DNS 配置越界发生于 **9/20**，相关训练/内部推理于 **10/1** 恢复，不是 10/24 新事故。
- **主要观点/创新点**：真正的隔离验收要假设内层沙箱甚至宿主已失守，再测外层是否仍阻断未授权外联、跨环境访问和副作用。高算力多 Agent 红队被纳入训练安全案例；离线内容保留浏览技能练习，却隔开实时外网。
- **可信度/局限**：公司自述；未公开全部路径和独立审计，不足以证明所有缺陷消失。内部研究环境不能外推到用户产品。
- **研究/大厂价值**：为自有 Agent 沙箱绘制“进程—VM—宿主—服务身份—出口网络”边界图，做授权故障注入，记录首个失守层、残余阻断、检测和恢复时间。

### 2. Agent 取证与记忆删除：从答案转向运行证据和来源闭包

- **事实/日期**：[AgentTriage](https://arxiv.org/abs/2610.30738) v1 为 **10/22 05:09 UTC（北京时间 13:09）**；作者提出跨运行时规范化事件、来源图和确定性诊断合同，并在五类运行时及 120 个裁定案例上报告结果。[AfterDeleteBench](https://arxiv.org/abs/2610.31366) v1 为 **10/22 14:41 UTC（北京时间 22:41）**；用合成秘密比较“暴露后删除”与“从未暴露”两组，指出派生摘要/分量可保留重建信息。
- **主要观点/创新点**：安全结论应引用真实运行事件，证据缺失时弃权；删除请求要沿原文—摘要—索引—记忆的派生图做闭包测试。前者可在同一规范化轨迹上重放诊断，后者用 never-exposed 配对对照分离旧暴露影响，并区分重建、写回与新会话召回。
- **可信度/局限**：均为预印本；结果取决于作者选定运行时、合成秘密、模型和响应接口，不能外推真实泄露率或所有商用产品。
- **研究/大厂价值**：用假数据做 MCP/RAG 审计作品，保存事件证据 ID、派生版本与删除回归，同时报证据覆盖、弃权、删后残留、正常任务成功和 P95。

## 具身智能单列观察（近 72 小时补读）

- [Progress Probes P²](https://arxiv.org/abs/2610.31613) v1 为 **10/22 17:40 UTC（北京时间 10/23 01:40）**。作者从 VLA 内部激活训练轻量线性进度探针，在仿真/真机操作任务中报告可与外部 VLM 监测竞争的失败检测表现。**创新**：低成本复用策略表示。**局限**：探针与策略可能共因失效，失败检测不是物理制动。**价值**：与独立传感器并测漏报、误报、P95、停机距离和恢复。
- [OpenTac](https://arxiv.org/abs/2610.31661) v1 为 **10/22 17:59 UTC（北京时间 10/23 01:59）**。作者将法向/剪切触觉皮肤、CAD 设计、仿真、跨传感器迁移与采样工具联为一体，报告 30 多种设计和四种真机本体应用。**创新**：把制造、感知与控制放入可迁移接口。**局限**：漂移、标定失效和接触安全尚缺充分独立证据。**价值**：做传感器血缘、标定和物理限值监控。
- 两篇均非 10/24 新稿，更不能推出机器人已具备无人值守安全等级。

## 中毒与侵入单列观察

| 方向与证据 | 前提、链路、成功指标 | 影响、防御效果和可复现性 |
|---|---|---|
| 训练环境越界；OpenAI **10/23 披露历史事件/受控红队** | 内部研究环境的隔离或配置失效；以未授权外联、宿主访问和跨环境通信为指标 | 官方称已加强补丁、网络限制、监测和自动暂停；完整独立审计未公开，不能外推所有产品或说是 10/24 新事故 |
| 邮件低信任内容；[AgentPhishing](https://arxiv.org/abs/2610.31404) **10/22 15:07 UTC v1** | 邮件 Agent 可读攻击者内容并拥有后续工具权限；除识别钓鱼外，测是否执行恶意请求 | 作者在受控九 Agent 基准中报告部分系统遵从恶意请求；不是现实入侵统计。应以最小权限、动作确认和实际副作用回放防御 |
| 记忆/知识库派生污染；AfterDeleteBench **10/22 v1** | 敏感或低信任内容进入摘要、索引与持久记忆；测删后重建、写回、跨会话召回 | 来源闭包删除、never-exposed 对照和回归测试比仅删原文更可验；合成任务不能证明所有商用系统同样失效 |

未核验到 **10/24 新发生**的真实数据中毒、权重后门或 Agent/MCP 侵入案例。所有实验应在自有隔离环境使用假账户和合成内容，不涉及第三方系统利用。

## 可落地的研究与求职作品

做一个“**可重放 Agent 工具取证＋删除闭包**”最小系统：在自有 MCP/RAG 沙箱设置正常查询、低信任文档误导和删除后查询三类合成任务；给工具调用绑定身份、授权、真实副作用及证据 ID；把索引、摘要和记忆作为派生节点做删除回归。交付任务成功、越权漏拦、误拒、证据覆盖/弃权、删后残留、P95 与恢复成本。扩展到具身仿真时另加独立传感监测和急停，不用文本 Agent 指标替代物理安全指标。
