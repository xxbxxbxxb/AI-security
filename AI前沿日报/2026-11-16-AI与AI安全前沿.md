# 2026-11-16 AI 与 AI 安全前沿

> 资料窗口：北京时间 2026-11-16 00:00—24:00，对应 UTC 11 月 15 日 16:00—11 月 16 日 16:00。本期于北京时间 11 月 17 日补写。arXiv 时间按 v1 提交时间核对；预印本数字均为作者报告，不能视作同行评审或独立部署结论。公司公告只有日级日期时，不推断其北京时间发布时间。

## 一、仍值得长期追踪的热点

1. **Agent 的外部控制面**：对工具结果、记忆、调用参数和实际副作用分别做来源检查、权限检查、不可绕过的运行时门禁与恢复演练。
2. **安全评测的有效性**：从单轮拒答或一次性攻击成功率，转向多轮任务、攻击预算、未见场景、误拦成本和独立复核。
3. **具身智能的双层闭环**：世界模型/VLA 负责高层动作提议，接触力、碰撞约束、急停、监护进程和人类接管必须在更快的底层闭环验收。
4. **中毒与侵入的生命周期**：训练数据、权重、RAG/长期记忆、KV 缓存、插件依赖及机器人场景包均需记录写入者、版本、传播范围、撤销和删除闭包。

## 三、AI 核心、安全与产业

### 1. K2-Horizon：开放完整训练过程的模型系列

- **事实**：K2 团队在 [arXiv:2611.21003](https://arxiv.org/abs/2611.21003) 发布 v1（11 月 16 日 12:28 UTC），描述六个从 0.9B 稠密模型到 375B-A23B MoE 的模型，并提出 Mixture-of-Value Attention、softplus attention gating、Uno 无损扩散解码适配器。论文声称公开中间检查点、预训练数据、日志及训练/评测代码。
- **主要观点与创新点**：将架构、解码、训练轨迹与评测一起开放，才便于研究人员检查能力来源、训练异常和安全退化；MoVA 把专家路由扩展到 attention value 投影，Uno 试图无需独立草稿模型加速解码。
- **可信度/局限**：规模、性能和开放范围来自团队技术报告；本期未逐项校验权重、数据许可与日志完整性，也没有独立同配置基准。预印本不等于已通过同行评审。
- **学习与求职价值**：选小模型复现一条“数据—中间检查点—评测—安全回归”链，比只比较排行榜更能展示训练系统与模型治理能力。

### 2. SilentGuard：工具 API 的静默错误由运行时拦截

- **事实**：[arXiv:2611.20595](https://arxiv.org/abs/2611.20595) v1 于 11 月 16 日 06:22 UTC 提交。作者在 15 个公开研究 API 中发现 11 个存在请求被部分忽略而仍返回 HTTP 200 的静默失败；基于正确 API 应满足的不变量，SilentGuard 在工具运行时扣留违规结果。论文报告目标故障上的错误回答率在 7 个开放模型中从 74.0% 降至 1.7%，在 3 个前沿模型中从 70.2% 降至 0.5%。
- **主要观点与创新点**：警告模型“注意数据错误”不够；把约束检查放在工具结果进入模型之前，能阻止貌似合理的错误证据继续传播。
- **可信度/局限**：数字是作者选定 API 和故障类型上的实验；对未知故障仍有错误，方法主要靠拒答而非修复，未证明企业 API 的全部语义均可由不变量覆盖。
- **学习与求职价值**：做一个只读工具网关，检查过滤器、分页、计数、时间范围和 schema 不变量；记录误拒、漏拦、P95 延迟与人工恢复率。

### 3. HEAMS 与 MemDoctor：把 Agent 记忆当作受治理的数据系统

- **事实**：[HEAMS，arXiv:2611.20144](https://arxiv.org/abs/2611.20144) v1 提交于 11 月 15 日 17:26 UTC，落在本期北京时间窗口。其评测覆盖性能、效率、安全、隐私和用户自主权；作者发现性能高的记忆系统可能同时有泄露、删除不彻底和中毒问题，检索及保留策略能改善投毒抵抗力，但可能降低帮助性。[MemDoctor，arXiv:2611.21019](https://arxiv.org/abs/2611.21019) v1 提交于 11 月 16 日 12:38 UTC，将多模态记忆拆为写入、更新、检索、回答四阶段及九类错误，并按证据回溯后修复对应阶段。
- **主要观点与创新点**：HEAMS 将“记忆是否忠实服务用户”变成多维评测；MemDoctor 将最终答错追溯到最早受污染的记录阶段，避免只修答案、不修污染源。
- **可信度/局限**：两篇都是预印本，HEAMS 的治理权衡与 MemDoctor 的修复收益由作者在各自基准报告；“引用到了记忆”仍不足以证明记录来源可信，真实多租户、跨设备同步和删除闭包需另测。
- **学习与求职价值**：搭建合成记忆回归集，逐条保存来源、写权限、版本、TTL、纠错记录和删除传播；同时汇报任务成功率、污染传播率、隐私泄露率与恢复时间。

### 4. 欺骗性模型与 KV 缓存完整性：审计对象必须考虑规避审计

- **事实**：[欺骗性模型审计，arXiv:2611.20459](https://arxiv.org/abs/2611.20459) v1 于 11 月 16 日 03:27 UTC 提交。作者用安全博弈构造既在目标能力上故意低表现、又保持其他能力并抵抗黑盒/白盒审计的模型样本。[KVMark，arXiv:2611.20454](https://arxiv.org/abs/2611.20454) v1 于当日 03:23 UTC 提交，提出对多 Agent 间传递的 KV 缓存做内容绑定的脆弱水印；作者在 1500 次受控传递中报告 100% 篡改检出和 0% 误报。
- **主要观点与创新点**：审计模型不应只测“容易抓住的坏模型”；多 Agent 的非文本状态传递也需要完整性保护。前者引入会主动规避审计的压力测试，后者把完整性校验从文本扩展到内部张量。
- **可信度/局限**：前者是人为构造的模型样本，不等于真实模型已欺骗；后者的完美数字只对论文的模型、扰动和预算成立，不能直接泛化到跨版本、异构推理栈或真实中间人事件。
- **学习与求职价值**：研究审计时同时报告“检测率、正常任务保真、可适应性”；研究缓存时把签名/上下文绑定、重放检测、版本迁移和性能开销纳入供应链测试。

## 四、具身智能单列观察

### 1. ForceHarness：让高层模型读懂力，同时把快闭环留在底层

- **事实**：[arXiv:2611.21099](https://arxiv.org/abs/2611.21099) v1 于 11 月 16 日 13:44 UTC 提交。作者用腕部传感器或关节力矩估计力，以自主终止的力控制原语在底层调节接触，再把带不确定性的物理量交回冻结的多模态模型。作者在其无腕部力传感器的实机任务中报告 GPT-6 Astra 零样本成功率由 3.3% 升至 90.0%，并在仿真基准报告提升。
- **主要观点与创新点**：API 模型的决策频率不足以直接闭合接触力控制；工具原语作为更快的控制层，使力信息可被高层模型理解。
- **可信度/局限**：实机与仿真数字均为作者报告，任务数量、设备与对照条件有限；成功率不是接触安全、近人部署或抗干扰证明。
- **学习与求职价值**：可做模型频率与控制频率分层实验，重点测峰值力、接触超调、硬件时延、异常传感器、监护进程与急停后状态。

### 2. VLA-SSD 与 ThinkWAM：推理时延和动作修正的两条路线

- **事实**：[VLA-SSD，arXiv:2611.20460](https://arxiv.org/abs/2611.20460) v1 于 11 月 16 日 03:28 UTC 提交，将 flow-matching 动作头蒸馏为随机单步策略；作者报告动作头前向时间缩短 7.7 倍，蒸馏后 LIBERO 成功率相对下降 5.5%，再经 GRPO 后训练对 π0.5 VLA 相对提升 20.6%。[ThinkWAM，arXiv:2611.21258](https://arxiv.org/abs/2611.21258) v1 于当日 15:30 UTC 提交，先提出动作片段、用该提案校正潜在未来、再由同一动作头生成修正片段；作者报告多基准收益，双次推理平均每片段约 101—165 ms。
- **主要观点与创新点**：前者通过一步随机策略同时降低 rollout 成本、增加 RL 采样多样性；后者让预测未来真正依赖拟执行动作，在执行前自我修正。
- **可信度/局限**：均为预印本与作者基准。两个数字的硬件、策略和任务设置不同，不能直接做横向优劣排序；实机扰动、接触安全和端到端 P95 尚待独立验证。
- **学习与求职价值**：把端到端周期拆成感知、世界模型、动作生成、下发与安全过滤；同时报告成功率、每步 P95、碰撞/超力率和资源消耗。
