# 2026-W39 AI、AI 安全与具身智能周报

> 覆盖窗口：北京时间 2026-09-20 至 2026-09-26。
> 
> 实际材料：[[2026-09-20-AI与AI安全前沿]]、[[2026-09-21-AI与AI安全前沿]]、[[2026-09-22-AI与AI安全前沿]]、[[2026-09-23-AI与AI安全前沿]]。9 月 24—26 日没有已记录日报；因此本周结论只代表四份已有材料，不把缺报解释为“没有新动态”，也不使用旧闻填充缺口。
> 
> 证据口径：官方公告只证明发布或表态发生，不自动证明性能和安全效果；arXiv 按预印本和作者实验记录处理；公司案例保留公司口径；论文日期按原页面记录，UTC 转北京时间仅用于窗口判断；跨来源判断标为综合推断。中毒与侵入只保留防御性威胁模型、指标、影响和响应，不提供攻击载荷或未授权操作步骤。

## 一、本周结论

1. **Agent 基础设施、上下文/记忆与安全运营正在合并成同一控制面。** 阿里把模型训练/推理、Agent Native Cloud 和 Context Engine 放进一张路线图；Google 将私有云计算延伸到持续记忆；Merlin 把检查点放在下一次工具执行前。综合推断是：竞争单位已从单一模型 API 变成“身份—来源—记忆—权限—工具—结果—恢复”的可观测状态机，但这些发布仍主要是公司方案或厂商评测，尚未证明端到端安全。
2. **持续记忆同时放大能力和污染面。** 加密、设备密钥和隔离 enclave 可降低云端直接读取风险，却不保证记忆内容真实、来源完整或行为授权正确；《The Price of Safety》提示防御本身会造成误隔离。后续评测必须把保密性、完整性、效用和可撤销性分开验收。
3. **具身智能的高信号进展集中在“中间接口 + 闭环评测”。** SeeQ 将长任务信用分配拆到子任务，SkelWAM 用共享骨架连接不同本体，H2RBench 用 Real-to-Sim 相关性筛选实验，BarrierFormer 用预测式 barrier critic 提前约束风险，SHS 则把环境接触变成大力操作的支撑资源。共同缺口是跨硬件、接触失效、延迟、急停和恢复证据不足。
4. **运行时注入、越权和供应链完整性应与权重中毒严格分开。** 本周核验到的是触发式间接提示注入、工具调用意图检查和记忆防御代价；没有足够新证据确认 9/20—26 的训练数据/权重后门、RAG/MCP 真实入侵事件。缺少记录不是风险消失，仍需定向补查。
5. **研究与工程的共同评价单位正从平均成功率转向尾部风险和恢复。** 应同时记录候选覆盖、碰撞/TTC、力或约束违反、越权率、误隔离、P95 延迟、急停/回滚时间和干净任务效用；单次 benchmark 高分或厂商自测 F1 都不足以支撑生产结论。

## 三、研究创新点

1. **把工具调用检查前移到可执行边界。** Merlin 不尝试解释私有思维链，而是联合用户请求、工具历史、候选调用和 schema 判断下一步动作。这提供了“来源/授权/实际参数”联合建模的接口，但仍需与确定性授权和隔离并用。
2. **让持续记忆成为可审计的系统资产。** Google 的设计把设备密钥、云存储、隔离处理和透明日志接在一起；研究问题从“模型能否记住”变成“谁能写入、谁能读取、如何删除、如何证明恢复”。
3. **长任务控制的中间表示更具体。** SeeQ 用子任务与价值估计缩短信号回传，SkelWAM 用共享几何状态与本体解码分离语义和执行；两者都提供比端到端黑盒更可测的消融和故障注入点。
4. **Sim2Real 开始被当作评测问题而非宣传口号。** H2RBench 固定人类视频、场景、物体和任务，尝试用仿真排序预测真实表现。相关性可作为实验筛选信号，但必须补充真实接触失败、恢复和跨本体验证。
5. **预测式安全控制与物理接触资源结合。** BarrierFormer 用未来轨迹预测提前修正约束；SHS 将环境支撑纳入人形操作策略。两条路线都把安全和能力耦合到闭环动力学，要求同时测失稳、滑移、支撑丢失和急停。
6. **安全研究开始量化防御的正常流量代价。** The Price of Safety 把误隔离、正常任务成功率、检索证据和延迟纳入验收，提醒“攻击成功率下降”不能单独代表防御有效。

## 四、具身智能专题

| 子方向 | 本周变化 | 证据边界 | 下一步应测 |
|---|---|---|---|
| VLA | SeeQ 将长任务分解为当前子任务与 Q 值；KINO 以关键帧隔开语言规划和全身控制 | 预印本、有限任务/硬件 | 子任务误识别、关键帧覆盖、候选 N、端到端延迟和回退 |
| 世界模型 | DexTouch-WM、TAO-Force、Agile-WAM 延续视觉—触觉/力觉预测路线；本周未出现新的独立复现 | arXiv 作者实验，触觉硬件范围有限 | 触觉漂移、传感器失效、异常力、控制饱和和低层安全盾 |
| 机器人操作/导航 | H2RBench 提供人到机器人 Real-to-Sim 操作筛选；SHS 利用环境支撑提升人形大力操作 | 4 个任务或单平台实验；移动导航覆盖缺口 | 遮挡、接触丢失、滑移、未见物体和导航恢复 |
| 人形与移动机器人 | KINO 在 Unitree G1 上验证关键帧控制；SHS 在 G1 上验证支撑策略 | 预印本，非长期现场运行 | 力矩/接触上限、跌倒保护、断网行为、人工接管和维修率 |
| 触觉与多模态感知 | 视觉与触觉/力觉被放入 world-action model 或分层控制；本周缺少新的标准化触觉评测 | 任务和硬件有限，尚未独立复现 | 视觉—触觉冲突、校准 provenance、接触误报、延迟和退化 |
| 跨本体学习 | SkelWAM 用 25 维共享骨架与本体约束解码器；强调几何接口而非逐关节对应 | LIBERO-Cross10 有限 episode，43.3% 为作者数字 | 坐标/单位审计、不可达姿态、未见本体、碰撞和回退 |
| 仿真到现实 | H2RBench 报告仿真—真实排名相关；KINO/SHS 补充真实 G1 结果 | 相关性依赖任务与方法配置 | 固定示范/算力/随机种子，报告排名一致性、接触失败和长时漂移 |
| 数据集/评测 | H2RBench 将人类示范量和机器人示范量纳入同一操作评测；本周没有新高信号触觉数据集 | 4 个任务，会议录用状态未独立确认 | 置信区间、失败分类、跨机器人和真实危险事件 |
| 实时控制 | Agile-WAM 报告 11.9 ms 推理延迟；Merlin 47.49 ms 单样本，语义复检可能更慢 | 指标来自不同硬件/设置，不能直接比较 | P50/P95、控制周期超时、watchdog、慢速检查 + 快速硬约束 |
| 物理安全 | BarrierFormer 预测式屏障、KINO 关键帧、SHS 支撑策略共同把安全接口下沉到动作层 | 学习/预印本结果，不是形式化或现场安全认证 | 独立急停、约束违反、恢复时间、误停和人机共域故障注入 |

**周度判断：** 具身智能本周的主线不是单一大模型参数增长，而是把语言/视觉计划转换为可检查的子任务、关键帧、共享几何和预测式约束，再进入低层控制。安全验收应采用双路径：上层记录来源、历史、世界模型和候选动作；下层以独立控制器、速度/力矩边界、watchdog、急停和安全姿态限制物理后果。任何能力收益都应与接触失败、延迟和恢复一起报告。

### 5.1 本周事件与研究矩阵

| 方向 | 攻击前提与链路（防御性摘要） | 成功指标/影响范围 | 防御效果与优先控制 | 复现状态 |
|---|---|---|---|---|
| 触发式间接提示注入 | 攻击者能影响被检索文本，触发条件在上下文中保持；外部内容 → agent 状态改变 → 工具调用 | 有限实验中状态改变工具调用均值约 16.5%；影响运行时权限和数据/状态写入 | 摄取阶段结构检测、来源追踪、记忆/压缩审计、执行前授权、撤销与恢复；报告漏检、误报、延迟 | arXiv 预印本，未本地复现；不提供触发载荷 |
| 工具调用越权 | 低信任内容诱导候选调用，参数 schema 合法但不符合用户意图 | Merlin 在步骤数据上 F1 90.51%、召回率 88.45%；实际影响取决于工具权限和执行结果 | 语义检查 + 确定性资源授权 + 最小权限 + 沙箱；审计整条轨迹而非只看分类 | 厂商数据，未核验端到端 ASR、独立留出集或分布漂移 |

| 权重/训练数据后门 | 本周窗口内未核验到同时具备原始来源、明确前提、成功指标和复现信息的新事件 | 不把“未记录”写成攻击失败或无风险 | 持续使用 Model BOM、签名/哈希、隔离评测、触发/干净对照、回滚 | 本周覆盖缺口，列入定向补查 |

| MCP/插件/依赖供应链 | 恶意能力声明、过期证书或依赖进入发现/调用链；权限随服务身份扩大 | 错误解析、未授权调用、撤销失效和能力漂移 | Agent BOM/SBOM、发布者绑定、证书撤销、版本锁定、调用日志和回滚 | 本周未核验新真实案例；工程控制优先 |

### 5.2 统一事件响应字段

对任何后续案例，至少保存：受影响资产与版本、首次失守边界、请求者与执行身份、原始输入及来源、模型/工具轨迹、网络/文件/控制动作、成功与干净指标、影响对象、发现/隔离时间、凭证撤销、干净版本、恢复与回归结果、第三方通知、残余权限和未决归因。自然语言摘要只作索引，不能替代原始证据。

## 六、攻防趋势

| 趋势 | 攻击/失效侧变化 | 防守侧变化 | 本周判断 |
|---|---|---|---|
| 从内容到行动 | 触发文本、记忆条目和候选工具调用可跨越聊天界面改变状态 | 执行前检查、资源级授权、实际结果审计和可撤销权限 | schema 合法不等于授权正确 |
| 从隐私到完整性 | 持久化状态即使加密，错误内容仍可能长期影响行为 | 把密钥、来源、版本、删除和恢复分别建模 | 保密性不能替代 provenance |
| 从单模型到资产图 | 模型、adapter、RAG、记忆、插件、证书和控制器相互依赖 | Model BOM + SBOM + Agent BOM 与运行时轨迹关联 | 静态清单必须能支持隔离和回滚 |
| 从平均分到尾部风险 | 少数触发状态、接触丢失或 OOD 扰动决定真实后果 | 固定误报率比较漏检、碰撞/TTC、误隔离、P95 延迟和恢复 | 失败分布比单一均值更有决策价值 |
| 从模型自检到分层控制 | 高层模型、监控器可能共享同一污染源或延迟过高 | 慢速语义检查 + 独立实时控制器 + 硬约束/急停 | 安全收益必须连同延迟、误停和效用损失发布 |
| 从承诺到可验证治理 | 公司路线图和合作声明增多，但访问边界和结果公开不足 | 独立评估、证据留存、触发阈值、复测窗口和恢复演练 | 关键问题是整改是否可观察、可复测 |

## 七、对研究生学习/进大厂的启示

### P0：身份贯穿、可撤销工具调用的 Agent 安全网关

实现“请求者身份 → 检索/工具候选 → 资源级授权 → 执行或人工升级 → 不可信结果回流 → 全轨迹日志 → 撤销/回滚”。验收跨租户拒绝、超时、取消、凭证失效和 UNKNOWN 写入结果；同时报告正常成功率、越权阻断率、误拦截、P95 延迟和恢复时间。

### P1：具身双路径实时安全仿真

在隔离仿真中给 VLA/ROS2 栈建立 Model BOM、SBOM 和状态来源记录，接入关键帧或共享骨架接口；高层做语义/来源检查，低层独立执行速度、力矩、禁区、watchdog 与急停。加入传感器冲突、触觉漂移、adapter 版本变化、历史乱序和接触丢失，记录触发/无触发成功率、危险动作率、控制周期、急停与回滚。

### P1：复现能力论文并加入安全消融

优先 H2RBench、SkelWAM、KINO 或 BarrierFormer 之一。先复现主任务，再增加缺帧、乱序、遮挡、噪声、过期本体状态、约束违反和拒绝/降级策略。面试时按“数据流—模块接口—消融—失败类型—系统代价”讲清楚，明确预印本与未复现边界。

### P2：把记忆防御做成效用曲线

用受控合成数据比较写入校验、来源标签、检索配额、TTL、执行前授权和恢复；同时保留干净流量回归。展示 ASR、干净成功率、误隔离、证据召回、token/延迟成本和恢复后残留，而不是只展示过滤率。
