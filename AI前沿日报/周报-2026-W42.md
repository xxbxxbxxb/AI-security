## 一、本周结论

1. **Agent 安全的最小验收单位从“批准了某个工具”推进到“批准的实际副作用与进程真实权限一致”。** NemoClaw 把沙箱身份、provider 路由与宿主凭证绑定；Approve What, Exactly? 要求用户签署规范化效果；MCP-FSD 则显示工具描述可能小于服务器进程的实际文件能力。综合判断：必须把 `请求者身份 → 工具契约 → 规范化副作用 → 批准绑定 → 进程权限 → 实际结果 → 审计/恢复` 串成同一条证据链，流量网关、批准卡或提示词单独一层都不足以证明安全。[NemoClaw](https://docs.nvidia.com/nemoclaw/user-guide/deepagents/release-notes/2026/10/12)、[效果绑定](https://arxiv.org/abs/2610.21063)、[MCP-FSD](https://arxiv.org/abs/2610.22301)。
2. **前沿模型的能力阈值、部署缓解、真实流量与独立评估必须分层。** Gemini 4 Argon 与 Muse Wonder 模型卡把未缓解能力和部署残余风险分别陈述；GPT-Live-1.1 的生产样本与定向合成难例出现不同结论；Anthropic 向 METR 提供嵌入式访问，但新独立报告尚未发布。公司自评、访问安排与第三方结论不能互相替代。[Gemini 4 Argon](https://deepmind.google/models/model-cards/gemini-4-argon/)、[Muse Wonder](https://research.meta.ai/static/muse-wonder-model-card)、[GPT-Live-1.1](https://deploymentsafety.openai.com/gpt-live-1-1/avoiding-deceptive-interactions-with-users)、[Anthropic 更新](https://www.anthropic.com/news/an-update-on-independent-evaluators)。
3. **中毒面从可见文本扩展到索引拓扑与模型复用链。** HNSW-RAG 论文把近似检索图的可达性和局部竞争纳入投毒评测；Clean Data Can Still Carry Backdoors 表明特定自然分布支持的视觉后门可在作者设置的干净数据蒸馏后保留。两项都是受控预印本，不是生产事故，也不能外推所有 RAG、LLM 或机器人策略；但足以要求 Data/Index/Model provenance 与重建/替换后的行为回归。[HNSW-RAG](https://arxiv.org/abs/2610.21464)、[蒸馏后门](https://arxiv.org/abs/2610.21208)。
4. **具身研究从单一任务成功率转向部署偏移、物理后果、指令冲突、实时预算与恢复。** LIBERO-RIG 固定任务只改变硬件/配置；WorldOracle 将世界模型预测与配对实物执行对齐；AutoAgent0 和 SafeDriveVLA 分别把运行时验证/恢复、语言—场景冲突置于动作前；T2-Z、Spark-0、FastVLA 再补环境适应、触觉和时延轴。跨论文综合趋势清晰，但组合故障、独立安全层和真实部署仍缺统一证据。
5. **Agent 安全评测开始审计“不变量”而不只看总分。** Jeva 显式建模空选项与候选顺序；One Task, Many Interfaces 检查语义等价接口；LinguaGuardBench 只替换语言；Shortcut Sensitivity 改变域划分、统计单位和格式。共同启示是：任务语义与实际动作不变时，路由和门禁不应因名称、语言、排序或计分捷径大幅翻转；即使稳定，也仍需硬权限层复核。
6. **Agent 提升产出后，人类判断、验证、审计与恢复成为显性瓶颈。** Anthropic 的 Scion 与内部就业研究分别报告代码仓库/CI 扩容和内部 Agent 使用变化；这些都是单家公司的一手自报，不能外推所有大厂招聘。但对研究生的稳健结论是：作品集应证明自己能定义验收、发现失效、限制权限并回滚，而不是只展示生成吞吐。
7. **本周没有在六份日报中核验到新的真实训练数据/权重中毒、RAG 失陷或 MCP 入侵事故。** 有受控攻击研究、历史公告和厂商安全控制更新；“未核验”描述的是覆盖范围，不代表现实风险不存在。10 月 18 日缺报进一步限制了全周完备性。

## 三、研究创新点

1. **效果绑定的 Agent 安全网关。** 把 NemoClaw 的沙箱身份/路由、效果绑定的确定性批准和 MCP-FSD 的真实权限验证组合为研究框架：批准对象不是工具名或模型叙述，而是规范化副作用；执行前后分别核验进程能力与实际结果。可比较提示确认、可信确认、进程沙箱、三者组合的未授权副作用、误拒、P95、撤销和恢复残留。该组合是本周综合设想，尚无联合论文证明。
2. **索引拓扑感知的 RAG 完整性。** HNSW-RAG 表明 `文档来源正确` 不等于 `近似索引行为可控`；Librarian Agents 又把 Agent 生成的目录、摘要和引用变成长期工件。创新问题是同时版本化原文、合成工件与 ANN 图，比较 exact/ANN、增量更新、删除/重建后的检索与答案差异。
3. **部署偏移下的具身验证—恢复。** 以 LIBERO-RIG 的单轴 rig 偏移为基线，在 AutoAgent0 式独立验证层中加入组合故障，再用 WorldOracle 的预测—实物后果对齐检查恢复是否真实有效。重点不只是检测偏移，而是危险动作前剩余窗口、错误阻断代价和恢复后残留。
4. **跨语言、跨接口、跨格式的不变量评测。** 将语义等价接口、用户语言、候选排序和统计单位作为受控变量，固定实际工具动作与标签；同时报告路由准确、漏拦、误拒、真实副作用和模型方差，避免总 F1 掩盖捷径。
5. **能力—控制—部署—独立评估四层证据表。** 把模型卡的能力阈值、系统控制、真实流量样本和外部评估访问/报告分栏，避免“有第三方参与”被写成“已完成独立认证”。这可直接迁移到大模型采购、论文实验和公司风险评审。
6. **具身偏好、任务和安全约束的冲突解析。** LIBERO-PeRM 把任务与偏好拆开，SafeDriveVLA 把指令与场景冲突拆开；可进一步把不可协商的物理安全约束置于偏好之上，比较服从、谨慎执行、拒绝和恢复的效用代价。

## 四、具身智能专题

本周新材料以预印本作者实验为主，证据大多处于闭环仿真或有限实验室硬件层；没有形成 L4 真实部署安全共识。

| 子方向 | 本周变化与证据 | 仍需验证的安全边界 |
|---|---|---|
| VLA | [SafeDriveVLA](https://arxiv.org/abs/2610.20609)先判语言—场景冲突；[FastVLA](https://arxiv.org/abs/2610.22146)压缩视觉 token 以降低动作延迟；LIBERO-RIG 暴露 rig 偏移 | 不安全指令、关键视觉 token 丢失、组合硬件故障；联合测成功、碰撞/TTC、误拒、P95、急停与恢复 |
| 世界模型 | [WorldOracle](https://arxiv.org/abs/2610.18826)把预测与配对真机执行比较；T2-Z 用交互更新未知物理潜变量 | 视频逼真度不能代替接触后果；安全探索、错误潜变量、失败轨迹与预测不确定性需验收 |
| 机器人操作 | LIBERO-RIG 固定任务、改变相机/标定/控制/夹爪等 rig；Spark-0 用触觉监督视觉表征 | 目前多为仿真或有限真机；加入标定与触觉丢包、夹爪磨损、异常力、滑移和安全退回 |
| 导航/自动驾驶 | AutoAgent0 提出独立验证与恢复；SafeDriveVLA 用反事实严格服从预测判断指令冲突 | 作者闭环基准不是道路安全；补天气/传感故障、制动窗口、规则冲突、人工接管和真车证据 |
| 人形与多机器人 | [PingpongDuo](https://arxiv.org/abs/2610.20579)分离团队级目标/风险与个体技能；同日 GreenWAM 报告跨机器人共同动作空间 | 连续演示不等于接触安全；测伙伴延迟/失联、遮挡、近失碰、让位、急停和跨本体约束 |
| 移动机器人 | 本周没有充分独立的新通用移动导航主线；自动驾驶材料可提供验证—恢复接口参考 | 不能从驾驶仿真外推 SLAM/移动机器人；补动态障碍、地图新鲜度、定位失效和断联安全态 |
| 触觉 | Spark-0 让触觉既作输入也作视觉预训练监督 | 手套到机器人、本体差异、传感漂移、接触力峰值、滑移、丢包与急停尚待独立验证 |
| 多模态感知 | Gemini/Muse 的通用多模态能力与 Spark-0 的视觉—触觉表征分别推进，但证据层不同 | 通用模型卡不能证明 3D/物理执行；Meta 已承认 3D 视觉/空间推理局限，具身仍需专门感知与安全层 |
| 跨本体学习 | GreenWAM 声称共同动作空间覆盖多类机器人，PingpongDuo 使用分层协作 | 作者技术报告不证明未见本体安全泛化；核对代码、坐标/单位、动作可达性、碰撞和真实硬件规模 |
| 仿真到现实 | WorldOracle 以配对实物执行评估行动条件预测；T2-Z 有 4 项真机任务；LIBERO-RIG 明确仅仿真 | 仿真筛选、有限实验室硬件和真实部署分栏；需要组合扰动、多个种子、长期漂移和独立复测 |
| 数据集/评测 | LIBERO-RIG 提供 210 个扰动条件；LIBERO-PeRM 用 312 个任务拆分任务/偏好；WorldOracle 纳入成功与失败轨迹 | 冻结任务、资产、检查点和随机种子；报告分项而非混合总分，保留失败与缺失阶段 |
| 实时控制 | FastVLA 报告作者条件下仿真动作延迟下降 9–32%、Franka 端到端延迟下降 20% | 平均/单模块延迟不等于全链路 P95；加入传感、队列、网络、控制周期、watchdog、取消与急停 |
| 物理安全 | AutoAgent0 的动作前规则验证、SafeDriveVLA 的冲突判断和 LIBERO-RIG 的故障谱提供互补接口 | 都不能替代独立制动、限力/限速、故障安全态和恢复验收；重点测组合故障及误干预净收益 |

**周度判断：**具身研究正把“为什么会失败、何时能发现、拦截后怎么恢复”置于单一成功率之上。最有价值的后续闭环是 `部署偏移/低信任指令 → 世界状态与不确定性 → 候选动作 → 独立验证 → 执行/降级/停止 → 物理后果回放`。这是一项综合研究路线，不是本周论文已经完成的统一系统。

## 六、攻防趋势

1. **攻击对象下沉。** 从显眼恶意文本转向索引拓扑、自然分布特征、语义等价接口、宿主进程权限和多步工作流；“内容看起来正常”不代表执行链安全。
2. **防御边界外移到确定性系统层。** 沙箱身份、真实路径、最小权限、效果绑定、一次性调用和结果核对比让模型重复自检更可验；模型门禁仍用于处理残余语义风险，但不应拥有最终授权。
3. **评测从单一 ASR/F1 转向安全—效用—成本三联表。** 干净任务、未授权副作用、误拒/误隔离、P95、人工复核与恢复残留必须并列，避免高阻断率掩盖不可用性。
4. **具身攻防与 Agent 工具安全开始共享接口。** 两者都需要状态/来源、候选动作、权限/规则验证、实际副作用、停止和恢复；具身额外要求硬实时、不可逆物理后果和独立急停。
5. **公开透明度增加，但独立性仍受访问范围约束。** 模型卡、公司安全卡、嵌入式评估和产品审计字段更丰富；若没有完整采样、访问缺口、删节记录和外部报告，仍不能称为独立安全证明。

## 七、对研究生学习/进大厂的启示

1. **首选作品：效果绑定的本地 Agent 安全网关。** 用自有隔离目录和假文件构建 MCP/RAG Agent，交付 `工具契约 → 规范化副作用 → 人类确认 → 进程权限 → 执行结果 → 撤销/恢复`。加入中文/英文、接口别名、exact/ANN 和失败工具对照；报告任务成功、漏拦、误拒、P95 与残留，不接触第三方系统。
2. **具身论文切口要收窄。** 以 LIBERO-RIG 单轴偏移为可复现基线，只增加一项组合偏移与一层 AutoAgent0 风格验证—恢复；若没有真机，就明确停留在闭环仿真，不把碰撞减少写成物理安全认证。
3. **训练证据分级能力。** 每篇论文做四栏卡片：作者实验、可下载工件、本人复现、未解决边界；每个公司安全结论再拆成能力阈值、部署控制、真实分布和第三方评估。这比背诵模型排名更能体现研究与工程判断。
4. **把 Agent 产出和本人验收分开。** 面试时展示失败案例、评测脚本、权限矩阵、回滚证据与自己的判断；不要把模型生成页面、作者论文数字或公司内部指标写成自己的验证结果。
5. **补齐工程基本功。** 熟悉路径规范化、容器/进程最小权限、审计事件 schema、索引重建、版本/BOM、分层指标和回归测试；这些技能连接 RAG、Agent、MCP、AI 安全和具身运行时岗位。
